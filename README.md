## 03 / Featured project

### 🎵 Hybrid Music Recommendation System

<a href="https://github.com/prnvoid/hybrid-music-recommendation-system">
  <img src="https://img.shields.io/badge/EXPLORE%20PROJECT-7C6EE6?style=for-the-badge&logo=github&logoColor=white" alt="Explore project"/>
</a>

**An exploration of data-driven music discovery, personalized recommendations and the long-tail problem.**

A project that brings together several of my interests: data preprocessing, feature extraction, similarity search, collaborative filtering and machine learning.

**Inside the project:**

| Area | What I worked on |
|:--|:--|
| Dataset | Free Music Archive (FMA Small) |
| Data processing | Metadata cleaning, missing-value handling and dataset alignment |
| Audio analysis | MFCC, Chroma, Spectral Contrast and Tonnetz |
| Feature extraction | Librosa |
| Content-based retrieval | Cosine Similarity |
| Collaborative filtering | Rank-50 SVD |
| Similarity search | FAISS IndexFlatIP |
| Recommendation approach | Hybrid filtering with cold-start fallback |

**Some implementation details:**

- Worked with 8,000 tracks across 8 genres from the FMA Small dataset.
- Extracted 45-dimensional audio feature representations using Librosa.
- Constructed an interaction matrix involving 500 simulated users and 4,978 tracks.
- Processed 14,873 user–track interactions, with approximately 99.4% matrix sparsity.
- Implemented SVD-based collaborative filtering and audio-based similarity retrieval.
- Explored content-based fallback recommendations for tracks without interaction history.

**Preliminary evaluation**

| Metric | Result |
|:--|--:|
| Precision@10 | 0.112 |
| Recall@10 | 0.190 |
| F1@10 | 0.141 |

<sub>Evaluation uses simulated user interactions and should be interpreted as preliminary.</sub>

**Research directions:** Data-driven personalization · Long-tail discovery · Cold-start recommendation · User preference modelling · Serendipity.
